# Jiggle-X v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sandboxed macOS menu-bar app that keeps the Mac "user-active" (so Teams stays Available) during a user-set weekly schedule.

**Architecture:** AppKit `NSStatusItem` with separate left-/right-click `NSMenu`s, SwiftUI Settings/About windows. A pure `ScheduleEvaluator` + an `ActivityController` state machine (driven by a 15 s tick) decide when to call `IOPMAssertionDeclareUserActivity`. System services sit behind protocols so the state machine is unit-tested with fakes.

**Tech Stack:** Swift 5 language mode, SwiftUI + AppKit, IOKit power assertions, CoreGraphics idle time, ServiceManagement (`SMAppService`), XCTest. Hand-authored Xcode project (objectVersion 77, file-system-synchronized groups — no xcodegen available).

**Spec:** `docs/superpowers/specs/2026-10-22-jiggle-x-design.md`

## Global Constraints

- macOS deployment target **13.0**; `LSUIElement = true`; `SWIFT_VERSION = 5.0`.
- Sandbox entitlement `com.apple.security.app-sandbox = true`, **no other entitlements**. No Accessibility / Input Monitoring use.
- Bundle ID `com.jasonlowry.JiggleX`, tests `com.jasonlowry.JiggleXTests`, team `GT69QL2KK5`, automatic signing.
- Display name **Jiggle-X**; target/module **JiggleX**.
- Defaults: days Mon–Fri, start 08:00, end 18:00, idle threshold 120 s (allowed 30–240 s), Launch at Login **off**.
- Window is `[start, end)` local time; `end > start` required; no overnight windows.
- All user-facing strings via `String(localized:)` / `LocalizedStringKey`, English-only `Localizable.xcstrings`.
- Never declare activity unless state is `.active`.

## Review Focus

1. **Wake from sleep past window end** → first tick computes `.outsideHours` and does not nudge (test in Task 4).
2. **Relaunch after a "Pause Until Tomorrow" resume time has passed** → state is `.active`/`.outsideHours`, pause cleared (Task 4).
3. **DST transition day** (America/New_York 2026-03-08 / 2026-11-01) → 08:00–18:00 window still evaluated by wall clock (Task 2).
4. **Corrupt or invalid stored schedule** (undecodable data, `end <= start`, threshold out of range) → falls back to defaults / clamps (Task 3).
5. **Pause Until Tomorrow on Friday** → resumes Monday 08:00, not Saturday (Task 2 + Task 4).

### Task 4: System services + ActivityController state machine

**Files:**
- Create: `Shared/Models/RunState.swift`, `Shared/Services/SystemServices.swift` (protocols + system impls), `Shared/Services/ActivityController.swift`
- Test: `JiggleXTests/ActivityControllerTests.swift` (with `FakeIdleMonitor`, `FakeNudger`, `FakeClock`)

**Interfaces:**
- Consumes: `ScheduleEvaluator`, `PersistenceManager`, `PauseState`.
- Produces:
  - `enum RunState: Equatable { case active, paused, pausedUntil(Date), outsideHours }`
  - `protocol IdleMonitor { func secondsSinceLastInput() -> TimeInterval }` — `SystemIdleMonitor` uses `CGEventSource.secondsSinceLastEventType(.combinedSessionState, eventType: CGEventType(rawValue: ~0)!)`.
  - `protocol ActivityNudger { @discardableResult func declareActivity() -> Bool; func release() }` — `PowerAssertionNudger` uses `IOPMAssertionDeclareUserActivity("Jiggle-X: working hours" as CFString, kIOPMUserActiveLocal, &assertionID)`, reusing `assertionID`; `release()` → `IOPMAssertionRelease` and reset ID.
  - `protocol Clock { func now() -> Date }` — `SystemClock`.
  - `@MainActor final class ActivityController { init(persistence: PersistenceManager, idleMonitor: IdleMonitor, nudger: ActivityNudger, clock: Clock, calendar: Calendar = .autoupdatingCurrent); private(set) var state: RunState; var onStateChange: ((RunState) -> Void)?; func refresh(); func tick(); func pause(); func pauseUntilTomorrow(); func resume(); func start(); func stop() }`
    - `refresh()`: clear `untilNextWindow` if `now >= resumeAt`; derive state (paused → `.paused`; untilNextWindow → `.pausedUntil(resumeAt)`; else in-window → `.active` else `.outsideHours`); call `nudger.release()` when leaving `.active`; fire `onStateChange` only on change.
    - `tick()`: `refresh()`, then if `.active` and idle `>= schedule.idleThreshold` → `declareActivity()`.
    - `pauseUntilTomorrow()`: only when `.active`; resumeAt = `nextWindowStart(after: now)`.
    - `start()`: 15 s repeating `Timer` → `tick()`; observe `NSWorkspace.didWakeNotification`, `.NSSystemTimeZoneDidChange`, `.NSSystemClockDidChange` → `tick()`; tick immediately.

  - `testNeverNudgesOutsideHours`, `testNeverNudgesWhenPaused`
